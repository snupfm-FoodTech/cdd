알고리즘 개요

신장 질환 유형별 대체 레시피 추천 알고리즘은 신장질환 환자들이 건강을 유지하면서도 다양하고 만족스러운 식사를 할 수 있도록 돕기 위해 그래프 뉴럴 네트워크(GNN) 기반의 레시피 대체 시스템을 제공하는 혁신적인 기술입니다.

신장질환 환자들은 나트륨, 칼륨, 인, 단백질 등의 섭취를 엄격히 관리해야 하는데, 이 시스템은 환자의 질환 유형과 진행 단계를 고려하여 레시피 내 재료 간의 복잡한 상호작용을 분석하고 최적화된 대체 방안을 제공합니다.

📖

대체 레시피 추천

CVGAE 모델이 레시피 내 재료 간 관계를 학습하여 질환별 최적화된 대체 방안을 제공합니다.

핵심 특징

🎯
질환 맞춤형 레시피 대체
일반적인 건강 개선이 아닌 특정 질환별 식이 제한을 고려한 맞춤형 대체 방안을 제시합니다.
특징: 당뇨, 신장질환, 고혈압 등 질환 유형과 진행 단계를 반영한 재료 대체 기능
🔗
재료 간 상호작용 고려
개별 식품 대체가 아닌 레시피 내 재료 간 조합과 균형을 고려한 최적의 대체안을 제공합니다.
기술: GNN 모델을 활용하여 레시피 전체의 복잡성을 반영한 시스템적 접근
🧠
CVGAE 기반 학습
Conditional Variational Graph Auto-Encoder를 활용하여 영양 가이드라인을 만족하는 후보 식재료를 생성합니다.
방법: 기존 레시피와 대체 식재료 간의 영양성분, 조리방법, 맛 프로파일 관계 학습
🤖
LLM 활용 레시피 생성
대체 식재료를 바탕으로 Llama API를 통해 새로운 음식명과 조리방법을 자동 생성합니다.
기능: 기존 레시피의 맛과 영양을 유지하면서도 질환 제한사항을 만족하는 새로운 레시피 창조

작동 원리

알고리즘은 다음과 같은 6단계 프로세스를 통해 질환 맞춤형 대체 레시피를 생성합니다:

1
사용자 정보 입력
신장, 체중, 질환 종류 및 단계 정보 입력
2
음식명 입력
대체하고자 하는 레시피의 음식명 입력
3
대체 필요 식재료 선정
영양 가이드라인에 따른 제한 식재료 식별
4
후보 대체 식재료 생성
CVGAE 모델로 최적의 대체 식재료 도출
5
후보 대체 레시피 생성
LLM을 통한 새로운 레시피 제목과 조리법 생성
6
대체 레시피 추천
최종 맞춤형 대체 레시피 제공

핵심 기술 스펙

  • 핵심 알고리즘: Conditional Variational Graph Auto-Encoder (CVGAE)
  • 그래프 모델: Heterogeneous Graph Attention Network (HAN)
  • LLM 엔진: Llama API 활용
  • 후보 추천: 상위 5개 유사도 기반 대체 식재료
  • 처리 시간: 30초~2분
  • 지원 언어: 한국어, 영어

⚠️ 사용시 주의사항

  • 레시피 데이터베이스에 등록된 메뉴와 정확히 일치하는 음식명을 입력해야 합니다
  • 사용자 정보 (질환 정보 등)를 정확히 입력해야 적절한 영양 가이드라인이 적용됩니다
  • 생성된 대체 레시피는 참고용이며, 실제 식단 적용 전 의료진과 상담이 필요합니다
  • 시스템은 연구용 데이터를 기반으로 하므로 개인차를 고려한 추가 조정이 필요할 수 있습니다

활용 분야

이 알고리즘은 신장질환 환자를 중심으로 다양한 의료 및 건강관리 분야에서 활용 가능합니다:

신장질환 환자 식단 관리
만성콩팥병, 투석 환자 등 다양한 신장질환 환자들의 개별 맞춤형 식단 설계 및 관리
병원 영양상담 지원
임상영양사의 환자 상담 시 질환별 대체 레시피 제안을 통한 전문적 영양 상담 서비스
헬스케어 앱 서비스
질환자를 위한 모바일 헬스케어 앱에서 개인 맞춤형 레시피 추천 기능으로 활용
연구 및 임상 적용
질환별 식이요법 효과 연구 및 임상시험에서 표준화된 식단 설계 도구로 활용
