알고리즘 개요

LLM 기반 식이패턴 점수화 알고리즘(DPScore)은 사용자가 입력한 식이기록을 두 개의 LLM Agent로 분석하여 ① 음식 Category 추정, ② 섭취량(Portion) 예측을 수행한 뒤 8가지 국제적 Dietary Pattern Index를 자동으로 계산합니다.

기존의 수작업 식이평가를 초 단위로 단축하며, 일관성·재현성·확장성을 제공합니다.

작동 원리

DPScore는 다음 6단계로 점수를 산출합니다.

1
데이터 입력
식이기록(자유 형식 텍스트/CSV) 업로드
2
LLM-Agent A
Category 예측
음식명을 30여개 식품군으로 매핑
3
Validate A
룰·지식베이스로 카테고리 검증
4
LLM-Agent B
Portion 예측
텍스트·이미지 단위 섭취량(g/회) 추정
5
Validate B
영양 DB·허용범위로 용량 검증
6
Pattern 계산
8개 Dietary Pattern 스코어 산출

8가지 Dietary Pattern

EDIP
염증 유발·완화 식품 가중치 기반 점수
EDIH
인슐린 분비 영향 식품군 점수
WCRF
세계암연구기금 식이 가이드 준수 지표
DRRD
당뇨병 위험 감소 식이
DASH
고혈압 예방 식이 접근
hPDI
건강한 식물성 식단 지수
AMED
대안적 지중해식 지수
AHEI‑2010
건강한 식이 지수 2010

기술 상세

핵심 기술 스펙

  • LLM Agent: GPT‑4o 기반 커스텀 모델 2종
  • Validation Layer: 규칙 기반 + 영양DB 크로스체크
  • 처리 시간: 5 – 30초 (일일 3식 기준)
  • 지원 언어: 한국어·영어 (다국어 확장 중)
  • 출력: 8개 패턴별 점수(0‑10) 및 요약 리포트
  • 입력 형식: 텍스트, CSV, JSON (이미지 옵션)

⚠️ 사용시 주의사항

  • 식이기록에 브랜드·조리방법을 포함할수록 정확도가 향상됩니다.
  • LLM 특성상 드물게 오분류가 발생할 수 있으므로 임상 사용 시 영양사의 2차 검토를 권장합니다.
  • 이미지 입력은 실험 기능이며, 조명·해상도에 따라 오류가 증가합니다.
